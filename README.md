# Pokretanje aplikacije — Zelena mapa NS

## Preduslovi

- Node.js verzija 18 ili novija
- npm (dolazi uz Node.js)

## Kloniranje repozitorijuma

```bash
git clone https://github.com/strahinjap73-dotcom/zelena-mapa-ns.git
cd zelena-mapa-ns
```

## Ulazak u direktorijum aplikacije

Projekat sadrzi podfolder `zelena-mapa-ns` u kojem se nalazi izvorni kod:

```bash
cd zelena-mapa-ns
```

## Instalacija dependency-ja

```bash
npm install
```

## Pokretanje u development modu

```bash
npm run dev
```

Otvori browser i idi na `http://localhost:5173`.

## Build za produkciju

```bash
npm run build
```

## Preview produkcijskog builda

```bash
npm run preview
```
